# Streak Helper

Публичный информационный сайт приложения, политика конфиденциальности и поддержка.

- Сайт: https://ilya-88.github.io/streak-helper/
- Политика конфиденциальности: https://ilya-88.github.io/streak-helper/privacy.html
- Поддержка: https://ilya-88.github.io/streak-helper/support.html
- Обращения: https://github.com/ilya-88/streak-helper/issues

Сайт состоит из статических HTML и CSS. Рекламные и партнёрские размещения отключены 27 октября 2026 . Рекламные скрипты, отдельные аналитические счётчики и формы сбора данных отсутствуют. Публикация через GitHub Pages: ветка `main`, каталог `/ (root)`.

В этом репозитории размещены только публичные страницы. Исходный код приложения, установочные файлы, ключи, пользовательские данные и сессии Duolingo сюда не входят.

Независимый проект разработчика [ilya-88](https://github.com/ilya-88). Не является продуктом Duolingo и не одобрен Duolingo. Автоматическое прохождение не гарантирует сохранение серии и может противоречить правилам сервиса.

Перед подключением рекламы, платежей или изменением обработки данных необходимо обновить политику конфиденциальности под фактическую реализацию.
